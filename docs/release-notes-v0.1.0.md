# MDPeek 0.1.0

The first Windows release of MDPeek—a small, fast, read-only Markdown viewer.

## Highlights

- Open `.md` and `.markdown` files in a clean rendered view
- Document outline and heading navigation
- Copy selections as plain text, clean HTML, or Markdown
- Syntax-highlighted code with code-block copying
- Back and Forward document navigation
- Native print preview and Microsoft Print to PDF support
- Windows installer with respectful Markdown file registration
- Portable Windows ZIP

## Downloads

- **Setup** — recommended for normal Windows installation
- **Portable ZIP** — extract and run without installation
- **SHA256SUMS** — integrity hashes for both downloads

## Notes

This first release is unsigned, so Windows SmartScreen may display a warning. Download MDPeek only from this official GitHub repository and verify the SHA-256 checksum if desired. Windows may ask for confirmation before changing an existing default Markdown application.
